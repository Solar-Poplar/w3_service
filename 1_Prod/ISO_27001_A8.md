# ISO/IEC 27001:2022 附錄 A.8 控制措施 FAQ

# A.8.1 使用者端設備

## 1. 條文名稱
- 中文：使用者端設備
- 英文：User endpoint devices

## 2. 條文目的
建立與維持使用者端設備相關技術控制，降低資訊系統遭受未授權存取、竄改、洩漏或中斷的風險，確保資訊安全控制持續有效。

## 3. 稽核重點
- 是否建立相關政策、程序或技術標準。
- 是否完成系統設定並保留設定或管理紀錄。
- 是否定期檢視、監控及改善控制措施。
- 是否能提出客觀證據證明控制有效運作。

## 4. 常見問題（FAQ）

**Q1：稽核員通常會要求哪些證據？**  
A：系統設定畫面、政策、程序、弱點掃描報告、日誌、備份紀錄、變更紀錄、測試報告等。

**Q2：一定要導入專業資安工具嗎？**  
A：不一定，應依組織規模、風險及法規要求採用適當的技術控制，但需能證明其有效性。

**Q3：最常見的不符合事項有哪些？**  
A：設定未依程序管理、紀錄不足、權限管理不完整、弱點未追蹤改善或控制未定期檢討。

## 5. 相關知識
- ISO/IEC 27001 Clauses：4～10
- 常見文件：組態基準、備份政策、變更管理程序、弱點管理程序、SSDLC、網路架構圖
- 常見角色：IT、System Administrator、Network Administrator、Developer、ISMS Manager
- 相關控制：A.5（組織）、A.6（人員）、A.7（實體）

**Q3：最常見的不符合事項有哪些？**  
A：設定未依程序管理、紀錄不足、權限管理不完整、弱點未追蹤改善或控制未定期檢討。
