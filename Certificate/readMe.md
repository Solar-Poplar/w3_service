歡迎來到 **晟楊顧問有限公司（Solar-Poplar Consultant Ltd.）** 的 GitHub。

我們專注於資訊安全管理顧問服務，以及相關的隱私保護、工業控制系統資安、國際資安合規以及 AI 治理，協助企業建立符合國際標準與法規要求的管理制度，並提供顧問輔導、教育訓練、技術導入及安全評估等專業服務。

本 GitHub 將持續分享實務經驗、技術文件、範例程式、工具及最佳實踐，希望讓資訊安全更容易落實於企業與開發流程中。

關於本公司的介紹請參本公司[官方網站](https://晟楊顧問.tw)，這邊以討論為主。
