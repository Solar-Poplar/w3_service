網站剛推出，先以最常見與詢問度最高的 CISSP 與 Security+ 為主。

Security+ 與 CISSP 的主要差異在於適合對象與專業深度。Security+ 屬於入門至中階國際資安證照，適合資訊相關學生、IT 維運人員、系統與網路管理人員，以及希望轉職或踏入資訊安全領域的初學者。考試著重資訊安全基礎知識與實務應用，難度適中，具備基本 IT 經驗即可開始準備。CISSP 則屬於中高階管理型證照，適合已累積多年資訊安全或資訊科技實務經驗，並希望朝資安主管、顧問、架構師、稽核或治理與風險管理方向發展的專業人士。其考試涵蓋八大知識領域，強調情境分析、風險評估及管理決策能力，整體範圍更廣、深度更高，準備難度也明顯高於 Security+。因此，Security+ 適合作為資安職涯的起點，而 CISSP 則是邁向資安管理與領導職的重要里程碑。

## CISSP
- [CISSP     國際資訊安全專家認證](/Certificate/CISSP.md)

CISSP（Certified Information Systems Security Professional，國際資訊系統安全認證專家）是由 ISC2（International Information System Security Certification Consortium） 所發行與維護的國際級資安專業證照，也是全球最具代表性的資安管理證照之一。ISC2 為非營利國際組織，長期制定資訊安全專業能力標準與倫理規範，其證照受到政府機關、跨國企業、金融、醫療及關鍵基礎設施等領域廣泛採認，常作為資安主管、顧問及高階技術人員的重要專業能力證明。

CISSP 著重於資訊安全管理與整體治理能力，而非單一技術產品操作。考試涵蓋八大知識領域（CBK），包括安全與風險管理、資產安全、安全架構與工程、通訊與網路安全、身分識別與存取管理、安全評估與測試、安全營運，以及軟體開發安全。試題強調情境分析、風險判斷及管理決策，要求考生能從企業經營與資安治理角度思考，而非僅依技術細節作答，因此被公認為難度較高且具實務深度的國際資安證照。

CISSP 特別適合具備數年資訊安全或資訊科技實務經驗，希望朝資安管理、治理或顧問方向發展的專業人士，包括資訊安全主管、IT 經理、資安工程師、系統架構師、稽核人員、風險管理人員及資安顧問等。對於需要規劃企業資安策略、建立管理制度、推動法規遵循或帶領資安團隊的人員而言，CISSP 能有效展現其具備國際認可的專業能力與管理視野，也有助於提升職涯發展與企業信任度。

## Security+
- [Security+ 國際網路資安專家認證](/Certificate/Security+.md)


CompTIA Security+ 是由 CompTIA（Computing Technology Industry Association） 所發行的國際資訊安全專業證照。CompTIA 成立於 1982 年，是全球知名的非營利資訊科技產業協會，長期致力於建立資訊技術專業能力標準，並推出 A+、Network+、Security+、CySA+、PenTest+ 等多項國際認證。Security+ 被視為資安領域最具代表性的基礎至中階證照之一，受到政府機關、企業及教育機構廣泛採認，亦是許多企業培育資安人才及評估專業能力的重要參考依據。

Security+ 著重於資訊安全核心知識與實務應用能力，考試內容涵蓋一般安全概念、威脅與漏洞管理、安全架構、網路防護、身分識別與存取控制、密碼學、安全作業、事件回應、風險管理及法規遵循等主題。試題除測驗觀念理解外，也強調情境分析與問題解決能力，要求考生能依據不同環境選擇適當的安全控制措施。整體難度屬於入門至中階，相較於偏重管理治理的 CISSP，更著重於實務技術與日常安全維運能力，是建立資安專業基礎的重要認證。

Security+ 適合希望進入資訊安全領域的學生、資訊相關科系畢業生，以及從事系統管理、網路管理、IT 維運、技術支援、雲端服務或資安初階工作的專業人員。對於企業而言，也適合作為新進資安人員、SOC 分析師、資安工程師及資訊管理人員的能力培訓與評估基礎。由於 Security+ 涵蓋完整的資訊安全基本觀念與實務技能，取得證照後可作為進一步挑戰 CySA+、PenTest+、CASP+ 或 CISSP 等中高階國際資安證照的重要基礎，協助建立完整且循序漸進的職涯發展路徑。
