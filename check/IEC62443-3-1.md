# IEC 62443-3-1：Security Technologies for IACS

> **定位：** IEC 62443-3-1 並非規範「必須符合哪些要求」，而是介紹工業自動化與控制系統（IACS）可採用的各種資訊安全技術，作為系統設計與導入時的參考指南。

# 什麼是 IEC 62443-3-1？

IEC 62443-3-1 全名為 **Security Technologies for IACS**。

它的目的不是定義稽核要求，而是說明在工業控制系統中，可以使用哪些資安技術來降低風險，例如：

- 身分驗證
- 存取控制
- 網路分區（Segmentation）
- 防火牆
- VPN
- IDS / IPS
- 白名單
- 惡意程式防護
- 備份與復原
- 日誌與監控
- 加密技術

因此，3-1 可視為 IEC 62443 系列中的「技術指南」。

# 與其他 Part 的關係

| Part | 主要目的 |
|------|----------|
| 3-1 | 說明有哪些安全技術可使用 |
| 3-2 | 風險評估、Zone & Conduit、SL-T |

# 常見安全技術

## 身分驗證（Authentication）

確認使用者、設備或服務的身分，例如：

- 密碼
- 憑證
- MFA
- Kerberos
- LDAP / Active Directory

---

## 存取控制（Access Control）

確保使用者只能執行被授權的操作，例如：

- RBAC
- 最小權限
- 帳號管理
- Session Timeout

---

## 網路分區（Segmentation）

將不同安全需求的設備隔離。

常見方式：

- Zone
- VLAN
- Firewall
- DMZ

---

## 安全通訊

保護傳輸資料：

- TLS
- IPsec VPN
- SSH
- OPC UA Security

---

## 系統完整性

降低系統遭竄改風險：

- Secure Boot
- Code Signing
- File Integrity Monitoring
- Application Whitelisting

---

## 惡意程式防護

- Anti-virus
- Application Control
- USB Control
- Sandboxing

---

## 日誌與監控

- Syslog
- SIEM
- Wazuh
- IDS
- Security Event Monitoring

---

## 備份與復原

- Offline Backup
- Disaster Recovery
- Configuration Backup
- Redundancy

# OT 與 IT 的差異

| IT | OT |
|----|----|
| 重視 Confidentiality | 重視 Availability |
| 可頻繁更新 | 更新需停機評估 |
| 設備生命週期短 | 設備生命週期長 |
| 可快速更換 | 更換成本高 |

因此，相同技術在 OT 環境需考量即時性、穩定性與設備相容性。

# 導入建議

1. 先完成 IEC 62443-3-2 的風險評估。
2. 決定 Target Security Level。
3. 依 IEC 62443-3-3 選擇需符合的 Security Requirements。
4. 參考 3-1 選擇適合的安全技術。
5. 建立驗證與維運機制。

# 常見誤解

## Q：3-1 是驗證標準嗎？

不是，它屬於技術指引，不直接作為符合性要求。

## Q：是否必須全部採用？

不用。應依風險評估結果及系統需求選擇合適技術。

## Q：Firewall 就等於 IEC 62443？

不是。Firewall 僅是眾多安全技術之一，無法單獨滿足 IEC 62443。
