# IEC 62443-2-2：Implementation Guidance for an IACS Security Program

> **定位：** IEC 62443-2-2 提供 IEC 62443-2-1 的實務導入指引，協助企業將 IACS Security Program 落實到日常管理。

# 什麼是 IEC 62443-2-2？

2-2 並非新增管理要求，而是提供 2-1 的實作建議，協助企業建立一致且可持續運作的 OT 資安管理機制。

# 與 2-1 的關係

| 標準 | 功能 |
|------|------|
| 2-1 | 定義應建立哪些管理制度 |
| 2-2 | 說明如何落實這些制度 |

# 導入重點

- 管理責任分工
- 安全政策推動
- 資產盤點
- 教育訓練
- 變更管理
- 委外管理
- 稽核機制
- 持續改善

# 常見管理流程

- PDCA 循環
- 風險評估
- 管理審查
- 內部稽核
- 矯正措施

# FAQ

1. 2-2 是否可驗證？
2. 是否必須全部照做？
3. 如何與 ISO 27001 整合？
4. 是否適合中小企業？
5. 是否能搭配 3-2 一起導入？

# 總結

2-2 是 2-1 的實作指南，可協助企業建立可落地、可維護的 OT 資安管理制度。
