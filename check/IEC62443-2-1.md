# IEC 62443-2-1：Establishing an IACS Security Program

> **定位：** IEC 62443-2-1 提供建立工業自動化與控制系統（IACS）資訊安全管理計畫的方法，是整個 IEC 62443 系列中偏向管理制度的核心標準。

# 什麼是 IEC 62443-2-1？

IEC 62443-2-1 著重於建立與維護 IACS 資安管理制度，內容涵蓋：

- 資安政策
- 組織角色與責任
- 風險管理
- 資產管理
- 人員管理
- 事件管理
- 持續改善

可視為 OT 領域對應 ISMS 的管理框架。

# 適用對象

- 工廠營運單位
- OT 資安主管
- 系統擁有者
- 顧問
- 稽核人員

# IACS Security Program 主要內容

- 建立安全政策
- 定義組織角色
- 人員能力管理
- OT 資產管理
- 風險管理
- 變更管理
- 備份與復原
- Incident Response
- 稽核與持續改善

# 與 ISO 27001 的差異

| ISO 27001 | IEC 62443-2-1 |
|------------|---------------|
| 適用所有資訊系統 | 專注 IACS / OT |
| Annex A 控制措施 | OT 管理要求 |
| ISMS | IACS Security Program |

# 建議導入流程

1. 定義管理範圍
2. 建立 Security Program
3. 建立制度與程序
4. 執行風險管理
5. 內部稽核
6. 持續改善

# 總結

2-1 著重建立 OT 的管理制度，是後續 3-2、3-3 技術要求的重要基礎。
